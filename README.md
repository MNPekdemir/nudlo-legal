# Nudlo legal & support pages

Buildless, bilingual static pages for the local-first Nudlo app.

- Privacy: https://mnpekdemir.github.io/nudlo-legal/privacy.html
- Terms: https://mnpekdemir.github.io/nudlo-legal/terms.html
- Support: https://mnpekdemir.github.io/nudlo-legal/support.html
- Turkish pages: the same files under `/tr/`.

Developer display name: MNPekdemir. Contact: mnpekdemir.apps@gmail.com.

Confirmed first-version architecture: local app storage, no developer-operated app-data server, no ads or analytics. Apple system services, user-controlled backups, email support and GitHub hosting are described separately. Update these disclosures before adding account creation, sync, analytics, new third-party SDKs or a different purchase model. Review the released app against these pages before App Store submission.

GitHub Pages serves the root of `main`; `.nojekyll` disables Jekyll. Edit the HTML and CSS, then push to update the site. The source contains no tracking scripts, cookies or third-party assets.
